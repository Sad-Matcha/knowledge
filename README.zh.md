## 📌 提交说明

1. 所有作业均为本课程独立完成的作品。
2. 作业仅用于课程评估和评分。
3. 不得将这些作品用于其他课程。

## ❗ 备注

成品作业均放置在每个标有日期的作业文件夹内。

使用前请务必阅读以下内容！

1. 按下键盘按键 "Windows（似“田”字）" + "Tab（Q左边）" 打开桌面界面
2. 选择“新建桌面” （桌面2）
3. 按下键盘按键 "Ctrl" + "Windows（似“田”字）" + "←（左方向键）" 即可返回桌面1
4. 同理，→（右方向键）切换至桌面2
